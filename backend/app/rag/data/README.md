# RAG 検索インデックス

このディレクトリのファイルは `backend/scripts/build_index.py` が生成したものです。
アプリの実行時に必要なため、生成物ですがリポジトリにコミットしています。

| ファイル | 内容 |
|---------|------|
| `guidelines_vectors.npz` | 埋め込み行列（float32・659×3072・L2正規化済み） |
| `guidelines_chunks.json` | チャンク本文・ページ番号・出典情報 |

再構築の手順はリポジトリルートの `README.md`「検索インデックスの再構築」を参照してください。

## データの出自とライセンス

**`guidelines_chunks.json` に含まれるテキストは、このリポジトリの著作物ではありません。**
文部科学省が公開する下記の文書から機械的に抽出・分割したものです。

出典：「【数学編】中学校学習指導要領（平成29年告示）解説」（文部科学省）
https://www.mext.go.jp/component/a_menu/education/micro_detail/__icsFiles/afieldfile/2019/03/18/1387018_004.pdf
（2026年7月25日に利用）

本データは文部科学省ウェブサイト利用規約（政府標準利用規約第2.0版準拠、CC BY 4.0互換）に
基づき利用しています。**再配布・改変して利用する場合も上記の出典表示が必要です。**

`guidelines_vectors.npz` は上記テキストを Gemini `models/gemini-embedding-001` で
ベクトル化した数値データで、同じ出典に由来します。

対象外**です。ルートの `LICENSE` を参照してください。
